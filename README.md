# Muneeb Tanveer — Shopify Developer & CRO Specialist Portfolio

A modern, high-performance, single-page portfolio website for **Muneeb Tanveer**, a freelance Shopify Developer & CRO (Conversion Rate Optimization) Specialist.

Built with a dark glassmorphism aesthetic, sleek gradients, responsive design, smooth CSS/JS animations, and zero heavy framework dependencies for ultra-fast loading speeds and 100 PageSpeed optimization.

---

## ✨ Features

- **Modern Glassmorphism UI**: Sleek dark mode styling (`#07090e` base), subtle glow effects, backdrop filters, and custom CSS variables.
- **7 Core Portfolio Sections**:
  1. **Hero**: Large title, introductory statement, stats counters, interactive dashboard preview card, and CTAs.
  2. **About Me**: Professional summary highlighting specialization in Shopify/Shopify Plus, custom themes, CRO, performance, APIs, maintenance, and technical consulting.
  3. **Services**: 8 specialized service cards with SVG icons.
  4. **Featured Projects**: Detailed case studies for `getsoul.com`, `dmfluxury.com`, and `nixon.com` with UI mockups, tech stack badges, key metrics, and direct links.
  5. **Skills**: Modern badges featuring Shopify, Shopify Plus, Liquid, JS, HTML5, CSS3, GraphQL, Shopify APIs, Checkout Extensibility, Shopify Functions, Git, and GitHub.
  6. **Why Work With Me**: Value proposition cards highlighting conversion focus, clean code, fast communication, and long-term partnership.
  7. **Contact**: Direct email with copy-to-clipboard, GitHub, LinkedIn, Upwork links, and an interactive contact form with Netlify Forms integration.
- **Value-Add Interactive Tool**: Real-time CRO ROI Estimator widget allowing potential clients to calculate revenue lift.
- **Performance & SEO**: Semantic HTML5, JSON-LD structured data, preconnected Google Inter fonts, and lightweight Vanilla JS.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup & ARIA accessibility compliance.
- **CSS3**: Custom properties, CSS Grid, Flexbox, backdrop-filter glassmorphism, and keyframe animations.
- **Vanilla JavaScript (ES6)**: Sticky nav, Intersection Observer scroll animations, clipboard copying, ROI calculator, and form handling.
- **Netlify Forms**: Native serverless form processing.

---

## 🚀 Running Locally

Since this is a lightweight static project with no build steps or bundlers required:

1. Clone or download the repository.
2. Open `index.html` in any web browser.
3. Alternatively, serve with any local HTTP server or via the Netlify CLI:
   ```bash
   npx netlify dev
   ```
